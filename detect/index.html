2. Схемы, дополненные микрофонами

Для подтверждения Эффекта Фрея часто используется корреляционный метод: сравнение радиочастотной огибающей с акустическим фоном.

  • Микрофоны-датчики: Используются электретные капсюли с расширенным диапазоном (до 40 кГц).
  • Схема включения: Радиосигнал (SDR) и аудиосигнал (Микрофон) подаются на многоканальную звуковую карту (например, Focusrite Scarlett).
  • Цель: Поиск кросс-корреляции между электромагнитным импульсом и возможным акустическим откликом в закрытых полостях или твердых телах.

3. Детектирование инфразвука (0.1 - 20 Гц)

Инфразвуковой компонент часто сопутствует психофизиологическим эффектам СВЧ.

Стек технологий для инфразвука:
- Датчик: Дифференциальный манометр или сейсмодатчик (геофон) низкой частоты.
- АЦП: 24-битный инструментальный логгер (например, на базе ADS1256).
- ПО: OBSPY (Python library) для анализа сейсмических/инфразвуковых данных.
- Визуализация: Спектрограммы с окном FFT > 16384 для высокого разрешения в НЧ.

4. Программный стек (Feature Extraction)

# Стек для извлечения признаков речи из огибающей:
1. GNU Radio (Блок Envelope Detector -> Low Pass Filter)
2. Python (Librosa, NumPy, SciPy)
3. Алгоритмы: MFCC (Mel-frequency cepstral coefficients) для классификации голоса.
4. ИИ: Модели семейства Whisper (Fine-tuned) для распознавания речи из шума.
* Примечание: Использование данного оборудования должно соответствовать местному законодательству о радиосвязи.
