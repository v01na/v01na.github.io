BIO-RF SIGNAL EXTRACTOR

GOOGLE AUDITORY EFFECT ANALYSIS TOOL v2026.2

1. Поддерживаемые форматы (Offline)

Для глубокого анализа огибающей и RMS-спектроида поддерживаются следующие типы файлов:

RAW IQ (.iq / .dat)
Сырые данные с SDR (RTL-SDR, HackRF).
WAV (32-bit Float)
Демодулированный AM/FM сигнал для очистки от шума.
FLAC / ALAC
Без потерь, для анализа высокочастотных гармоник.
JSON / CSV
Амплитудные логи полевых детекторов.

2. Потоковая демодуляция (Online Stream) LIVE MODE

Система поддерживает подключение внешних потоков для мониторинга в реальном времени:

  • WebSockets (WSS): Прямая передача IQ-семплов с удаленных серверов (SDR++ / SpyServer).
  • Icecast / Shoutcast: Анализ аудио-огибающей из радиовещательных потоков.
  • UDP Multicast: Для локальных промышленных датчиков СВЧ-излучения.
  • WebUSB: Прямое подключение SDR-приемника к телефону/ПК через браузер.

Монитор захвата

RMS: 0.000 STREAM: DISCONNECTED
ВНИМАНИЕ: Алгоритм Google Bio-RF требует калибровки под конкретный костный профиль. В случае обнаружения "голосов" в сигнале, используйте фильтр Spectroid Normalize для отделения технических шумов от диверсионного воздействия.
