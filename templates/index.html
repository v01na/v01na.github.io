📋 Уровень 1: Запросы о сохранении данных

  Срочно
Инструкция: Отправьте эти запросы в первый же день обнаружения проблемы. Цель - предотвратить уничтожение доказательств.

1.1 Запрос операторам связи о сохранении данных

Генеральному директору [ПАО «МТС»/ПАО «Т2 РТК Холдинг»/ПАО «ВымпелКом»/ЭР Телеком Холдинг] Адрес: [юридический адрес оператора] От: [ФИО заявителя] Адрес: [адрес заявителя] Телефон: [телефон] E-mail: [email] УВЕДОМЛЕНИЕ о необходимости сохранения доказательств Я, [ФИО заявителя], проживающий по адресу: [адрес заявителя], настоящим уведомляю о наличии оснований полагать, что оборудование связи, расположенное по адресу: [адрес базовой станции], может использоваться для генерации нестандартных физических воздействий. В период с [дата начала] по настоящее время мною и членами моей семьи фиксируются симптомы, указывающие на возможное применение: 1. Микроволнового слухового эффекта (эффект Фрея) 2. Инфразвукового акустического воздействия В целях сохранения возможных доказательств, в соответствии с Федеральным законом «О связи», ПРОШУ обеспечить сохранность следующих данных за период с [дата начала] по настоящее время: 1. ВЫСОКОЧАСТОТНЫЕ ДАННЫЕ ЭНЕРГОПОТРЕБЛЕНИЯ: - Показания счетчиков мощности с разрешением 1 секунда - Логи системы энергоменеджмента - Данные о потреблении по фазам 2. RF-ПАРАМЕТРЫ В РЕЖИМЕ РЕАЛЬНОГО ВРЕМЕНИ: - TX Power с частотой дискретизации 10 кГц - Параметры модуляции несущей - Beamforming configuration logs - Temperature monitoring per RF chain 3. СИСТЕМНЫЕ ЛОГИ УПРАВЛЕНИЯ: - SSH/VPN session logs - TR-069 команды и конфигурационные изменения - Firmware update history - Remote management access logs 4. СПЕЦИАЛИЗИРОВАННЫЕ МОНИТОРИНГИ: - Vibration sensor data - Acoustic emission monitoring - Spectrum analyzer captures Прошу подтвердить получение настоящего уведомления в течение 3 рабочих дней и сообщить о принятых мерах по сохранению указанных данных. Приложения: 1. Копия паспорта заявителя 2. График проявления симптомов с временными метками «___» __________ 202_ г. _____________________ [Подпись, ФИО]

Слуховые восприятия без внешнего акустического источника 2. Психологический дискомфорт, нарушения сна 3. Физиологические реакции: [конкретные симптомы] Указанные проявления имеют устойчивую корреляцию с работой оборудования связи, расположенного по адресам: [адреса базовых станций]. В обоснование требований указываю на наличие специфических симптомов, которые могут свидетельствовать о воздействии нестандартных физических факторов от оборудования связи, расположенного по адресам: [адреса базовых станций]. Для установления фактических обстоятельств дела имеют существенное значение следующие доказательства, находящиеся у операторов связи: 1. ТЕХНИЧЕСКИЕ ДАННЫЕ О РЕЖИМАХ РАБОТЫ ОБОРУДОВАНИЯ: - Логи энергопотребления с разрешением 1 секунда - Параметры RF-излучения с частотой дискретизации 10 кГц - Системные логи управления оборудованием - Данные об изменениях конфигурации 2. ДАННЫЕ МОНИТОРИНГА ОКРУЖАЮЩЕЙ СРЕДЫ: - Результаты спектрального анализа - Акустические измерения - Данные непрерывного мониторинга Самостоятельно получить указанные доказательства невозможно, поскольку они относятся к внутренней документации операторов связи. Истребовать у операторов связи [перечень операторов] техническую документацию и данные мониторинга, указанные в настоящем ходатайстве. 2. Истребовать у Управления Роспотребнадзора результаты специализированных измерений. 3. Назначить комплексную судебную экспертизу. Приложения: 1. Копия искового заявления 2. Копии запросов операторам связи 3. Медицинские документы «___» __________ 202_ г. _____________________ [Подпись, ФИО]

3.1 Заявление в Следственный комитет

Руководителю Следственного отдела по [району] СУ СК РФ по [наименование субъекта РФ] Адрес: [адрес следственного отдела] От: [ФИО заявителя] Адрес: [адрес заявителя] Тел.: [телефон] ЗАЯВЛЕНИЕ о преступлении по статьям 128.1, 119 УК РФ Я, [ФИО заявителя], проживающий по адресу: [адрес заявителя], с [дата начала] подвергаюсь систематическому противоправному воздействию, выражающемуся в: [Детальное описание]: 1. Применении специальных технических средств для несанкционированного воздействия на психику 2. Генерации микроволнового слухового эффекта (эффект Фрея) 3. Создании инфразвукового акустического давления 4. [Иные конкретные действия] Указанные действия причиняют мне физические и нравственные страдания, выражающиеся в: [перечень последствий для здоровья]. Имеются основания полагать, что для совершения указанных действий используется оборудование связи, расположенное по адресам: [адреса базовых станций], принадлежащее операторам: [перечень операторов]. В связи с изложенным, руководствуясь статьями 140-141 УПК РФ, ПРОШУ: 1. Возбудить уголовное дело по признакам преступлений, предусмотренных статьями 128.1 (Клевета), 119 (Угроза убийством), 111 (Умышленное причинение тяжкого вреда здоровью) УК РФ. 2. В рамках доследственной проверки истребовать у операторов связи: - Все логи и технические данные, перечисленные в приложении - Сведения о лицах, имевших доступ к системам управления - Данные об изменениях конфигурации оборудования 3. Провести выемку и исследование технического оборудования. 4. Назначить комплексные судебные экспертизы: - Судебно-медицинскую (последствия для здоровья) - Компьютерно-техническую (анализ логов) - Электротехническую (анализ параметров излучения) Приложения: 1. Копия паспорта заявителя 2. Медицинские документы 3. График проявления симптомов 4. Подробный перечень требуемых технических данных 5. Копии всех предыдущих обращений «___» __________ 202_ г. _____________________ [Подпись, ФИО]
